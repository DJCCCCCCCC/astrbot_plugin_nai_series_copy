# Plugin repository instructions

- Update `CHANGELOG.md` in every commit. Describe changes in Chinese under the unreleased section or the applicable release.
- Treat “git一下” as a release request. Bump the plugin version, move unreleased changes into the new release section, validate, then commit and push the release.
- When bumping the plugin version, update `metadata.yaml` and add a matching dated release section to `CHANGELOG.md`.
- Use Conventional Commits for commit messages.
